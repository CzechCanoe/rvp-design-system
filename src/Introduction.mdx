# CSK RVP Design System v2 „Klidná voda“

Design systém pro registrační a výsledkový portál **Českého svazu kanoistů**: kalendář závodů, výsledky, live výsledky, přihlášky klubů a profily závodníků.

## Co zde najdete

### Tokens

Paleta, stavy hodnot (Oficiální, Předběžné, V revizi, Neznámo, Live, Zastaveno), škály písma a mezer: **Tokens → Overview**.

### Components

Jednotlivé stavební bloky: tlačítka, formuláře, tabulky, stavové odznaky, časy, živé výsledky (`ResultsTable`, `OnCoursePanel`, `ProgramList`), kalendář po víkendech, přihláška klubu, profil závodníka.

### Stránky (Page stories)

Celé obrazovky složené jen z komponent DS, jedna na obrazovku z reference:

- **Live** – Running, Expanded, Startlist, Official, Disconnected, Program
- **Event → Detail** – detail závodu
- **Calendar → Season** – kalendář sezóny po víkendech
- **Entry → Club Entry** – přihláška klubu (úřad)
- **Athlete** – veřejný a mobilní profil
- **Layout** – Tribuna, Úřad a embed (`PageLayout`)

Stránky mají fixní čas a fake `Clock`, takže se nic neposouvá a snapshoty jsou stabilní.

## Ovládání v toolbaru

- **Theme** – světlý režim (tmavý se ve v2.0 nekreslí, vykreslí se světle)
- **Embed** – Standalone / Embed (pro kanoe.cz, `data-mode="embed"`)

## Principy

- Tři tóny jednoho systému: **Tribuna** (diváci, bílá), **Úřad** (šedá pracovní plocha), **Moje** (profil, telefon jako výchozí plátno).
- Stavy hodnot jsou páteř: komponenty přijímají `Observed<T>`, značky a stavy, ne doménu.
- Čas přes injektovaný `Clock`, nikdy `Date.now()` v komponentě.
- Pohyb jen u dat; `prefers-reduced-motion` se respektuje všude.

## Technické info

- React 18/19, TypeScript, CSS custom properties `--csk-*`
- Barlow Semi Condensed, IBM Plex Sans a IBM Plex Mono (self-hosted)
- Mobile-first, 390 px je výchozí plátno pro live a profil
- Přehled API: `docs/COMPONENT_API.md` (generováno `npm run docs:api`)
